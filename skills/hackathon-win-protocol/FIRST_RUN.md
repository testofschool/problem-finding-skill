# First-run checklist — hackathon-win-protocol

- [ ] `python3 scripts/win_case_gate.py` with no arguments prints PASS on the bundled sample.
- [ ] `python3 -B tests/test_win_case_gate.py`, run from a copy of the folder, ends with "0 failed".
- [ ] On a real contest, the first reply asks for (or states) the target and its signal before any idea.
- [ ] The site's terms were read before any page was saved.
- [ ] `read` phase: at least one page was saved and cited as `file:<path>`; no ruling rests on a summary.
- [ ] Every unstated or to-be-announced limit shows up as an open item with the question to send the organizer.
- [ ] No judge attribute without a source; every implication cites that judge's own published signal.
- [ ] Winners include at least one non-winner as control; blocked searches are named.
- [ ] No idea was proposed before `read` passed; the entrant, not the assistant, made the pick.
- [ ] Every heavy criterion has a row in the case table.
- [ ] The brief from `--report` was shown, in the entrant's language, with the phase verdicts.
